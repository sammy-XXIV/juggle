The Solution

What is Juggle?

Juggle is a 3D infinite runner built for Solana Mobile. Each lane the player surfs maps to a real perpetuals position on Pacifica.

Dodge candles, stay in the green lane, cash out before the market turns — every reflex trained in the game is a real trading instinct.

Not a simulation. Every run opens and closes a real testnet order on Pacifica's SOL-PERP market.

SKR Integration

The SKR Shield

Stake SKR before your run. Lose less when the market turns.

Players stake Seeker (SKR) tokens as a shield before each run. If the position closes at a loss, the shield absorbs a portion — then the staked SKR is permanently burned from supply.

Every losing run removes SKR from circulation. Juggle is a deflationary SKR sink baked into gameplay.

🔥

Burn signed by player's wallet via MWA using SPL Token Program burn instruction (index 8) — verifiable on-chain.
