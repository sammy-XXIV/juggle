SKR Integration

The SKR Shield

Stake Seeker (SKR) before a run. If the run ends in a loss, the shield absorbs part of it, and the staked SKR is burned on-chain.

Deflationary sink. Every losing shielded run removes SKR from supply. SPL Token burn, signed by the player via MWA.
